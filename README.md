# Recipe page

Frontend Mentor 新手题（Newbie），纯 HTML + CSS，无框架、无 JS。

- [Live site](https://youchuya.github.io/recipe-page/)
- [Challenge](https://www.frontendmentor.io/challenges/recipe-page)

## 学到什么

- 语义化：`article` / `header` / `section` / `ol` / `table`
- 本地字体：`@font-face` 三档字重 + Young Serif
- 表格：`border-collapse`、`table-layout: fixed`、`th` 默认样式修正
- 列表：`counter(list-item)` + `::marker` 自定义序号
- 响应式：`min()` + 一个 600px 断点，手机上图片贴边

## 设计还原

尺寸、字号、字重都是从 JPG 设计稿反推的（量文字宽度对字号）。
